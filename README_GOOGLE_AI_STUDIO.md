# Loto — extraction propre pour Google AI Studio

Cette archive contient uniquement les éléments appartenant au package de l'application `lnb.predict.earn`, plus les ressources Android décodées et les bibliothèques natives.

Code décompilé : 140 fichiers Java.
Écrans/composables : 19 fichiers.
Services/synchronisation : 8 fichiers.
Couche data : 41 fichiers.
Ressources Android : présentes dans `src/main/res`.
Manifest : `src/main/AndroidManifest.xml`.

Les noms `.java` sont issus de la décompilation JADX. L'APK original était écrit avec Kotlin/Compose, donc JADX reconstruit du Java à partir du bytecode Kotlin ; ce n'est pas le texte Kotlin original.

Le code de l'interface et de la logique est inclus autant qu'il est récupérable depuis l'APK. Les classes générées Hilt/Room présentes dans le package sont conservées car elles peuvent aider à comprendre les dépendances et la structure.
